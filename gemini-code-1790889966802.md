# Arquitectura del Proyecto: App de Moda Inteligente

## 1. Dependencias y Stack Tecnológico (package.json)

### Core & Framework
* **`next`**: ^14.0.0 (Framework React con App Router)
* **`react`**: ^18.2.0 (Librería UI)
* **`react-dom`**: ^18.2.0
* **`typescript`**: ^5.0.0 (Tipado estático)

### Backend & Datos (BaaS)
* **`@supabase/supabase-js`**: ^2.38.0 (Cliente oficial para base de datos, auth y storage)
* **`@tanstack/react-query`**: ^5.0.0 (Data fetching, caché y sincronización offline)
* **`zustand`**: ^4.4.0 (Gestión de estado global ligero en cliente)

### Interfaz de Usuario (UI) & Estilos
* **`sass`**: ^1.69.0 (Preprocesador CSS para SCSS modules y custom properties)
* **`swiper`**: ^11.0.0 (Carruseles interactivos y gestos táctiles)
* **`lucide-react`**: ^0.290.0 (Librería de iconos open-source y escalables)

### Procesamiento Local & PWA
* **`next-pwa`**: ^5.6.0 (Generación de Service Workers)
* **`@imgly/background-removal`**: ^1.2.0 (Eliminación de fondo por IA ejecutado en WebAssembly/Navegador)
